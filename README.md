Home SOC lab with Wazuh SIEM, Sysmon and Kali Linux – attack simulation and detection mapped to MITRE ATT&amp;CK
Värddator: Legion 7i, 32 GB RAM, VMware Workstation Pro 26.0.1
Hyper-V aktivt, därför används WHP. Det är ett bra exempel på ett problem du löste.
Labbnätverk: VMnet2, host-only, 10.10.10.0/24, IP-planen
